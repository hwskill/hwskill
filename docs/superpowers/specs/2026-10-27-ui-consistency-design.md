# 页面结构、卡片与主题交互统一

站点基于 shadcn preset b7ClMyaTC，统一页面结构、卡片和交互。内容列表按本站首次收录／发布时间倒序。

沿用现有架构与数据契约，保留贡献表单、中文译文和搜索候选规则。通过源码仓 PR 进行集成。

1. 内容卡片统一用 shadcn Card，采用元信息、标题、摘要、标签、页脚五个区域；推荐卡片抽为共享 Astro 组件，在首页、推荐目录、主题页、技能相关推荐和搜索结果中复用。技能卡片采用相同的间距、标题和页脚规则。长文、表单和内容列表保持不同任务需要的结构，但统一表面、圆角、字号与间距。
2. 导航右侧提供图标按钮，打开浅色、深色、跟随系统选项。默认跟随系统；手动选择跨页保存；重新选择系统后继续响应系统变化。首屏脚本在内容绘制前恢复主题。存储被禁用时页面内切换仍可用。保留键盘操作、选中状态及清晰名称。
3. 时间取 Git 首次添加日期（跟随条目 ID，兼容层级移动及推荐 YAML→Markdown 迁移），不取 checkout 修改时间、译文时间或上游观测时间。构建期读取历史，随站点保存当前条目的日期快照作为无 Git／浅克隆回退。没有证据的日期为空并稳定排后，不编造时间。同时间以 ID 排序。分类导航、流程步骤不属于时间列表。
4. 首页、技能目录、推荐目录、主题内容及相关推荐使用相同排序。关键词搜索保留相关性选取候选，但选出的结果和无关键词筛选都按时间呈现。日期显示为“收录／发布”，避免误导为上游创建时间。

验证：纯逻辑单元测试覆盖日期提取、移动、格式迁移、缺失日期、时区、稳定排序及主题偏好；浏览器覆盖首屏主题、跨页／刷新、系统切换、存储不可用、菜单键盘、卡片一致性、列表倒序、表单和搜索回归；完成全量测试、构建、索引和各类页面的明暗／移动布局检查。
