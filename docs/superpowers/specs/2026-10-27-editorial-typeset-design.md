# 内容优先的排版与容器层级

保留现有 Cyan 配色、字体策略、主题选择与业务功能。视觉层级由内容角色决定，减少同质化圆角、背景和阴影。

- 首页统计是轻量摘要：数字加文字，无背景、边框或圆角面板。
- 推荐是文章列表：标题、摘要、日期和细分隔线；首页技能采用开放的目录条目。
- 技能目录可以保留轻边界以支持扫描，但使用小圆角且不使用悬浮阴影。标签改为文字元信息。
- 表单控件保留明确边界和小圆角；表单区、步骤说明、安装区及辅助信息使用留白和分隔线，不层层嵌套面板。
- 中文长文与技能译文使用官方 shadcn/typeset 样式，保留 size/leading/flow 三项排版控制，字体沿用 Public Sans 与中文回退。布局单独控制阅读宽度，宽表格在保留 table 语义的容器内滚动。

参考：[Typeset 编辑器](https://ui.shadcn.com/typeset)、[官方说明](https://ui.shadcn.com/docs/typeset)。官方样式源码及 MIT 许可随文件保留。

验收：逐页检查容器层级，比较首页、推荐列表、长文与贡献表单的明暗及手机截图；验证统计区无面板、宽表格无页面溢出，保留搜索、排序、主题和表单行为。本轮先提供本地预览。
